# Initial Release

- Initial release of selenium-wrapper, a lightweight Selenium helper for browser automation.
- Adds a reusable `Wrapper` class for opening sites and interacting with elements by configured paths.
- Includes built-in waiting options and support for input, select, and radio interactions.
- Automatically checks and updates ChromeDriver to match the local Chrome installation.
- Provides a small execution helper and custom exceptions for clearer automation failures.
- Designed for Python 3.10+ with simple installation and minimal setup.
